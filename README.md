# Брокерская аналитика ФИНАМ

Одна HTML-страница, которая разбирает брокерские справки ФИНАМ и показывает,
сколько на самом деле стоит торговля: прибыль, все списания брокера и биржи,
ГО и обязательства — по дням, неделям, месяцам и инструментам.

**Файлы никуда не отправляются.** Справки разбираются прямо в браузере, на
вашем компьютере. Сервера нет. Разобранные дни сохраняются в хранилище вашего
браузера (IndexedDB), чтобы в следующий раз добавлять только новые справки.

**Не удаляйте скачанные справки — храните их в одной папке на компьютере.** В
браузере хранятся только результаты разбора, а не сами файлы. Когда выходит новая
версия страницы, которая достаёт из справки больше данных, страница попросит
загрузить справки заново: аналитика пересобирается из исходных файлов, а не из
хранилища браузера. Хранилище браузера к тому же может очиститься само (очистка
истории, режим инкогнито, другой браузер или компьютер).

Единственный запрос в интернет, кроме загрузки библиотеки графиков и шрифтов, —
к открытому API Мосбиржи за ставками фандинга вечных фьючерсов, и только если
ставки за какой-то день нет в самих справках. Номер счёта и данные справок в
этот запрос не попадают: в нём только код контракта и даты.

## Как пользоваться

1. Скачайте `index.html` из раздела Releases (или из папки `dist`) и откройте
   его в браузере (Chrome, Edge, Firefox).
2. В личном кабинете ФИНАМ выгрузите **полную** «Справку о состоянии
   обязательств» **за один день** — файл вида `… (01.10.2026 по 01.10.2026).xls`:

   **Личный кабинет → Счёт → Справка → Полная → дата (один день) → Excel**

   Сделайте так за каждый нужный день.
   - **Только полная справка.** В краткой нет сделок и расшифровки списаний,
     страница её не примет.
   - **Только за один день.** Из итогов за период нельзя разложить затраты по
     дням.
   - **Файл как есть.** Не открывайте и не пересохраняйте его в Excel.
3. Перетащите файлы на страницу или нажмите «Загрузить справки». Можно сразу
   десятки файлов и сразу по нескольким счетам. Неподходящие файлы (краткие
   справки, справки за период, другие отчёты, таблицы, пересохранённые в Excel
   файлы) страница отклонит и напишет причину. Повторная справка за тот же день
   заменит прежнюю.

## Что показывает

- **Сводка.** Стоимость счёта, прибыль за период без учёта ввода и вывода денег,
  вариационная маржа, все затраты в рублях, в процентах от прибыли, на лот и в %
  годовых от стоимости счёта.
- **Ставки брокера — из фактических списаний.** Сколько брокер берёт за контракт
  на срочном рынке и какой процент от оборота на фондовом рынке. Ставки
  выводятся из ваших же справок, а не из тарифа. Если ставка менялась, страница
  покажет, с какого дня и какой она была раньше. Рядом сверка по каждому дню:
  сколько брокер должен был взять по ставке своего периода и сколько взял.
  По фондам ФИНАМ брокер комиссию не берёт, их оборот в расчёт не входит.
- **Затраты по статьям:** брокер за сделки (срочный и фондовый рынок отдельно),
  биржевой сбор, ежемесячная плата, плата за недостаточность ГО, перенос и
  РЕПО, пени, маржинальный заём, прочие списания — с комментариями брокера.
- **Инструменты:** вариационная маржа, брокер, биржевой сбор и итог после затрат
  по каждому контракту или базовому активу; доля сделок, по которым биржа взяла
  сбор.
- **ГО и обязательства:** ГО и деньги по дням, долг, покрытый бумагами,
  требования и обязательства по расчётам, дни с платой за нехватку ГО, позиции
  на конец выбранного дня.

## Ограничения

- Учитываются рублёвые суммы. Валютные позиции в расчёт не входят.
- Брокерская комиссия в справке дана одной суммой за день. По инструментам она
  раскладывается по выведенной ставке за контракт.
- Справки краткого формата (без списка сделок) дают итоги дня, но не дают
  разбивки по инструментам и расшифровки неторговых списаний. Страница
  помечает такие дни во вкладке «Данные».
- Формат справки может измениться. Если что-то перестало сходиться, напишите,
  какой раздел справки поменялся.

## Как проверить подлинность

Распространять можно только оригинальный файл. Чтобы убедиться, что ваш файл
не изменён, сравните его контрольную сумму с опубликованной автором (в
описании релиза и в файле `dist/SHA256SUMS.txt`).

Windows (командная строка, в папке с файлом):

```
certutil -hashfile index.html SHA256
```

macOS и Linux:

```
shasum -a 256 index.html
```

Номер версии виден внизу страницы. Если сумма не совпадает с опубликованной для
этой версии — файл изменён, пользоваться им не стоит.

## Для разработки

Исходник — `src/index.html`, собранный файл — `dist/index.html`.

```
npm install
npm run build
```

Сборка сжимает код, подставляет версию и дату и пишет SHA-256 в
`dist/SHA256SUMS.txt`. Версия берётся из `package.json`.
